Getting here took one discovery: the server's SSRF request
filter blocks calls to 127.0.0.1 by default. The lab server
was restarted with SSRF_REQUEST_FILTER_WHITELIST=127.0.0.1
before this parse succeeded. A feed on a real host needs no
whitelist entry.

Creating the podcast (POST /api/podcasts) made the item, but
the episodesToDownload list in the create call was silently
ignored by v2.37.1 — see t09 for the route that works.
